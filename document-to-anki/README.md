# 文档转 Anki Skill（v1.1.0）

这是把 PDF、Word、扫描讲义、题库和复习笔记，转换成分层关键词背诵卡片的可复用 Skill。

## 本次更新（2026-10-31）

用户确认一份扫描资料制成的**牌组结构修正版 `.apkg`** 已成功导入 Anki，并且正反面答案可以正常显示。因此：

- 将该成功经验写成 `references/verified-success-case.md`，区分验证过的事实和推测的报错成因。
- 将 **静态格式检查 → 软件实际导入 → 正反面显示** 作为三个不同验收等级。
- 优先采用可靠的 Anki 打包库/官方接口和自带 `Front`/`Back` 模板的 APKG；CSV 作为备用。
- 新增 `scripts/verify_apkg.py`，对旧式 APKG 的 ZIP、SQLite、JSON、字段、卡片数量做静态检查（不能代替 Anki 实测）。
- 保留并强化 OCR 校对、跨题串入检查、关键词层级和考试答案完整性。

## 如何使用

在支持 Skills 的 AI 工具中安装该文件夹，或把 `SKILL.md` 作为附件上传给 AI。然后上传你的复习材料并发送：

> 请严格执行我提供的 `document-to-anki` Skill，将附件整理为适合 Anki 的复习卡片。先建立题目索引，按原文逐题核对；将答案归纳成一级关键词、二级分论点、三级完整作答；制作总框架卡、语义明确的分论点卡以及必要的整题论述卡。请优先生成带 `Front/Back` 正反面模板的 APKG，提供 CSV 备用，报告识别/校对风险。必须分别说明文件静态检查、Anki 实际导入及正反面显示的验证状态；不能把生成成功冒充导入成功。若无法运行 Anki，请提供我可以在手机或电脑上操作的最终验收步骤。

## 文件目录

```text
document-to-anki/
├── SKILL.md                              # 主流程与规则
├── README.md                             # 使用说明与复制用提示词
├── references/
│   ├── troubleshooting.md                 # 常见错误与解决方法
│   ├── verified-success-case.md           # 已验证成功的 APKG 案例及局限
│   └── acceptance-checklist.md            # 三等级验收与交付清单
└── scripts/
    └── verify_apkg.py                    # 旧式 APKG 静态检查脚本
```

## 使用与保护提示

- 首次试用新牌组时先进行小规模或隔离导入；已有复习记录不要直接删除或覆盖。
- 旧式 APKG 检查脚本支持内含 `collection.anki2` 的压缩包；对于较新的 Anki 存储格式，应采用相应 Anki 工具和真实导入验证。
- 用户已确认的成功是针对此前**那一个修正版牌组与其使用环境**，不能因此跳过下一份新材料的验收。
- 扫描文件即使可导入，也需要单独核对答案内容；技术成功不等于答案无误。
