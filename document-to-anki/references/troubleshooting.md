# Anki 常见故障与解决方案（更新自实际案例）

## 1. 正面出现 `#columns:ID,Front,Back,Tags`
**现象**：第一张卡显示 CSV 文件头而不是题目。
**常见原因**：Anki 未把 `#columns` 当元数据解析，例如文件写出器给整行套了引号、元数据格式不规范或导入器行为不匹配。
**处理**：使用无自定义头指令的标准 UTF-8 CSV，确认字段顺序；若有普通标题行，在导入时跳过；检查首张卡必须是真实题目。不要在原牌组中反复盲目导入。

## 2. 正面显示正常，翻面后没有答案
**常见原因**：Back 字段没有映射、模板引用字段错误、模板遗漏 `{{Back}}`、CSS 隐藏答案或答案字段本身为空。
**处理顺序**：① 在“浏览/编辑”检查字段是否真的有答案；② 核对正背面字段映射；③ 检查 Back Template 必须含对应的 `{{Back}}` 或其他实际字段名；④ 用简单模板排除 CSS 隐藏；⑤ 在卡片预览中再次翻面。
**经验**：CSV 中存在 Back 列不等于背面一定会显示它。

## 3. APKG 报 `500: JsonError { info: "decoding decks: JsonError" }`
**可能原因**：`collection.anki2` 中牌组/配置 JSON 缺少导入器所需结构、schema 版本兼容性问题或手工组装异常。
**真实案例**：先前失败包与后来的成功包均 ZIP/SQLite 正常，后者补齐 `decks` 中默认牌组和统计字段；用户随后确认 APKG 导入成功、背面内容可见。**不能证明某一个字段就是唯一根因。**
**处理**：优先通过当前兼容的 Anki 库/官方接口重新导出完整 APKG；检查 `models`、`decks`、`dconf`，以及 note/card 关系；在独立 Anki 真实导入测试。不能只做 ZIP、SQLite integrity_check 后就承诺成功。

## 4. 题目正确但答案混入另一道题
**原因**：OCR 读取扫描件时把相邻标题和正文连成一题；机械按段落拆分。
**处理**：核查题目索引、原文页码与扫描原图；将跨题内容拆回正确知识点，不确定部分标待核对。

## 5. 卡片数量增加，但背诵效率下降
**原因**：把原文按标点机械拆成若干“回忆第N段”卡，卡片重复率高、任务不具体，或正面把答案泄漏。
**处理**：以语义上的独立知识点为边界，优先总框架卡＋真实分论点卡；必要时另加整题模拟卡，不用张数代替质量。

## 6. 导入后出现重复卡、原有复习进度被打乱
**原因**：每次导出都重新生成不稳定笔记 ID/GUID，或把新牌组当旧牌组直接覆盖。
**处理**：保留稳定 GUID/原题索引；确认 Anki 导入更新策略，先备份、先导入临时牌组；未经用户允许不删除已有笔记或牌组。

## 7. 文件导入成功但答案存在扫描错误
**原因**：技术校验与知识校对是两件事。
**处理**：独立执行原题覆盖与逐题 OCR 校对；待核对内容标具体页码，不宣称卡片已成为标准答案。

## 状态报告模板
`文件生成：是/否；静态结构检查：通过/未通过/未测；实际 Anki 导入：通过/失败/未测；正反面显示：通过/失败/未测；内容逐字校对：已完成/部分/未完成。`
