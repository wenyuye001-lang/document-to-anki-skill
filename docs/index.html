把复习资料，变成真能背下来的 Anki 卡片

先校对，再制卡

扫描件最常见的问题是跨题串入：下一题的内容混进了上一题的答案。如果直接切卡，错误会跟着你背进考场。

  • 原文优先保留原资料的术语、学说和答题范围，不用一般知识悄悄“纠正”考试材料。
  • 每题可追溯原题、关键词、分论点、完整答案和卡片 ID 对应成一张核对表。
  • 不确定就标出来无法确认的内容标“待人工核对”和具体页码，不当作确定答案。
问：正当防卫的成立条件是什么？
答：须存在现时的不法侵害，且防卫行为未超过必要限度。共犯从属性是指教唆犯、帮助犯的成立…… 跨题串入，属下一题。回看页图，拆回原题。 校对示意，非真实资料摘录。

九步流程，顺序不能跳

  1. 原材料盘点统计页数、章节和题数，建立题目索引，标出漏页和模糊处。
  2. 逐题修复与校勘确定每题真实起止，修正 OCR，排查跨题串入。
  3. 形成背诵层级L1 关键词、L2 分论点、L3 完整答案，并区分原文与 AI 归纳。
  4. 设计卡片框架卡考结构，分论点卡考要点，论述卡考完整输出。
  5. 卡面排版手机优先，保证暗色模式可读，不依赖联网资源。
  6. 生成 APKG优先用可靠的 Anki 库或官方接口，不手拼数据库。
  7. 生成 CSV标准 UTF-8 备用文件，防止表头变成学习卡。
  8. 分三级验证静态检查、软件导入、正反面实测，各报各的结果。
  9. 最终交付写明题数、卡数、覆盖率和待核对题目。

“文件生成了”不等于“能用了”

Skill 要求 AI 如实报告验证到了哪一级，没有真实测试时不得声称“已验证可用”。

未验已生成文件存在，还没有做任何检查。
Level A静态检查通过ZIP、SQLite、JSON、字段和卡片数量都正常。AI 可执行。
Level B实际导入成功在隔离牌组中导入，无报错，数量和映射正确。
Level C正反面显示正常翻面能看到答案，手机宽度和暗色模式可读。

切勿把 Level A 写成 Level C。技术 Level C 也不代表扫描内容逐字无误。

这些规则来自一次真实踩坑

198张卡片

《外国刑法学》扫描 PDF 的制卡过程。经历三次失败后，最终的修正版牌组由用户确认导入成功，翻面能看到答案。

确认范围仅限这一份牌组。使用的 Anki 版本未记录，OCR 内容也未因此被确认逐字准确，所以每份新资料都要重新验收。

  1. 失败
    初版 CSV#columns:ID,Front,Back,Tags 被当成卡片内容，显示在了正面。
  2. 失败
    修复后的 CSV正面正常，背面空白。Back 列有数据，不等于模板会显示它。
  3. 失败
    初版 APKGZIP 和 SQLite 检查都通过，导入仍报 decoding decks: JsonError。
  4. 成功
    结构修正版 APKG牌组配置补齐后，导入和翻面都通过。这也成了内置检查脚本和三级验收的来源。

怎么使用

1. 安装 Skill

在 Claude Code 中，把技能文件夹复制到 skills 目录：

git clone https://github.com/wenyuye001-lang/document-to-anki-skill.git
mkdir -p ~/.claude/skills
cp -r document-to-anki-skill/document-to-anki ~/.claude/skills/

其他 AI 工具：安装 document-to-anki 文件夹，或把其中的 SKILL.md 作为附件上传。

2. 上传资料，发送这段话

请严格执行我提供的 document-to-anki Skill，将附件整理为适合 Anki 的复习卡片。先建立题目索引，按原文逐题核对；将答案归纳成一级关键词、二级分论点、三级完整作答；制作总框架卡、语义明确的分论点卡以及必要的整题论述卡。请优先生成带 Front/Back 正反面模板的 APKG，提供 CSV 备用，报告识别/校对风险。必须分别说明文件静态检查、Anki 实际导入及正反面显示的验证状态；不能把生成成功冒充导入成功。若无法运行 Anki，请提供我可以在手机或电脑上操作的最终验收步骤。
