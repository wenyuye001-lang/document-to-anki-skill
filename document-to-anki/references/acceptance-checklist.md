# 文档转 Anki 验收清单（可直接复制到工作报告）

## 一、知识内容（必须检查）

- [ ] 已统计页数、章节、原题数量并形成题目索引
- [ ] 已核对 OCR 错字、漏页、漏题与跨题串入风险
- [ ] 每一道原题都有对应卡片/排除原因/待核对状态
- [ ] 一级关键词并非机械截句，二级论点和三级完整答案一一对应
- [ ] 分论点卡有独立可检验的回忆目标，未过度重复
- [ ] 来源页码、题目 ID、校对状态与标签可追溯
- [ ] 扫描无法确认的内容已标注，不当作确定答案

## 二、技术静态检查（仅代表 Level A）

- [ ] 每张卡正面字段非空、背面字段非空
- [ ] 字段名称和正/背面模板引用完全一致（例如 `Front` / `Back`）
- [ ] 框架卡、分论点卡和长答案卡不存在明显溢出/隐藏 CSS
- [ ] CSV 重新解析正确，列数和标签列无错位，无元数据误入卡片
- [ ] APKG ZIP 无损坏、数据库 integrity_check 正常
- [ ] `col.decks`/`col.models` JSON 正常，牌组引用的模型、notes/cards 均存在
- [ ] 对旧式 `collection.anki2` 可运行 `python scripts/verify_apkg.py "文件.apkg"`

## 三、Anki 实际导入（Level B）

- [ ] 在隔离/临时牌组导入，无错误或警告
- [ ] 牌组卡片数量与预期匹配
- [ ] 笔记类型、字段映射、标签和牌组名称正确
- [ ] 不影响用户现有牌组或复习进度
- [ ] 已记录测试客户端和版本（未知则注明未知）

## 四、正反面显示（Level C）

- [ ] 正面显示题目和任务，未泄漏完整答案
- [ ] 点击“显示答案”后能看到背面正文
- [ ] 抽检第一张、最长答案卡、含 HTML/特殊字符卡和不同卡片类型
- [ ] 手机宽度、长内容滚动和深色模式可读
- [ ] 若由用户确认通过，明确记录只针对当前交付包

## 五、最终验收结论（四选一并明确说明）

- `已生成（未验）`
- `Level A：静态检查通过，未在 Anki 导入`
- `Level B：Anki 实际导入成功，尚未完整确认翻面显示`
- `Level C：Anki 导入成功，卡片正反面正常显示`

**切勿把 Level A 写成 Level C。** 技术 Level C 也不代表扫描内容逐字无误。
